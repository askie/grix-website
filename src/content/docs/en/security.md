## Communication Security

- Encrypted WSS persistent connections
- Token-based authentication with automatic re-login on expiry

## Multi-Device Management

View all logged-in devices and remotely remove any device.

## AI Agent Security

- **Execution Approval** — Agent command execution requires user approval (Allow once / Always allow / Deny)
- **Permission Control** — Fine-grained Scope authorization for each agent
- **Key Management** — Encrypted storage, rotation support, one-click invalidation on leak

## Data Privacy

- Grix **does not** send chat data to third-party AI model providers
- Minimal data collection
- Local cache can be cleared by users at any time
- Supports complete account deletion (irreversible)

## Reporting

Report users/groups: Select reason → Add details → Upload screenshots → Submit.

## Security Best Practices

1. Regularly check your device list
2. Default AI approval to "Allow once"
3. Never share agent API keys
4. Use a strong password
