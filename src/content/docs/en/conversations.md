The message list is Grix's main home view, showing real-time activity across all conversations.

## Conversation List

### Conversation Aggregation

Grix groups multiple conversations under the same contact. Click to expand and view all conversation threads with that contact:

- Latest message preview and timestamp
- Unread count badge
- **@You badge** — special indicator when someone @mentions you in a group chat
- Online/offline status indicator

### Conversation Actions

Long-press or right-click (desktop) a conversation to access:

| Action | Description |
|--------|-------------|
| Pin | Pin the conversation to the top of the list |
| Unpin | Remove pinned status |
| Mark as read | Clear the unread badge |
| Mark as unread | Manually mark as unread |
| Mute notifications | Do-not-disturb — no push notifications for this conversation |
| Unmute notifications | Restore push notifications |
| Delete conversation | Delete local chat history (does not affect friendship) |

## New Chat

Click the "+" button at the top of the message list to:

- **New direct message** — Select an existing friend to start a conversation
- **New group chat** — Select multiple friends to create a group

## Search Conversations

The search bar at the top of the message list supports fuzzy search by conversation name or contact name for quick navigation.

## Scan QR Code

Click the scan icon to launch the camera and scan QR codes:

- **Add friend** — Scan another user's Grix friend QR code
- **Join group** — Scan a group QR code to join
- **QR Login** — Scan a desktop/web login QR code to confirm

## My QR Code

Display your Grix friend invitation QR code. Supports copying the link and downloading the QR code image.

## Desktop Agent Toolbar

On Grix Desktop (macOS / Windows / Linux), a row of **agent toolbar icons** appears at the top of the message list:

- Small icons showing all deployed AI agents
- Real-time status colors: 🟢 Online / 🟡 Busy / 🔴 Offline
- Click an icon to quickly open the corresponding agent's conversation
- Grouped by agent client type

## Web Notification Permission

When using the Grix web version in a browser for the first time, a notification permission banner appears at the top. Click "Enable" to allow Grix to push browser notifications.
