Access the "Settings" tab in the bottom navigation to manage your profile and account settings.

## Personal Profile

- Avatar (crop, rotate), nickname, username (can only be changed once), bio
- My QR code

## Change Password

Email verification code → Set new password → Log in again.

## Account Settings

### Appearance

Dark mode / Language (11 options) / Font size / Chat background (color/image)

### Chat Preferences

| Setting | Description |
|---------|-------------|
| Text delegation | Auto-reply new friend conversations with a specified agent |
| Voice delegation | Auto-answer incoming calls with voice AI |
| Friend request policy | Require approval / Auto-accept / Disabled |
| Allow being added to groups | Allow / Deny |

### External Integration

- **Website Integration** — Create a chat Widget → Get embed script → Paste into your website
- **Webhook Integration** — Global webhook management

## Other Features

- **Notifications** — Permission status, request permissions
- **Privacy** — Data summary, privacy policy, delete account
- **Storage & Data** — Cache statistics, clear image/chat cache
- **Device Management** — Logged-in device list, remote logout
- **Help & Feedback** / **About** (version number)
- **Log Out**
