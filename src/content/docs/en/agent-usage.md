How to use agents day-to-day after successful integration.

## Starting a Conversation

Entry points: AI list "Chat" button / Message list / Desktop toolbar / Contacts AI assistant.

## Conversations and Working Directories

Each agent conversation can be bound to a working directory (cwd). Conversation list is grouped by directory.

## New Conversation

Agent conversation list → "New Conversation" → Agent requests working directory selection → Submit to start.

## Agent Message Types

| Card Type | Description |
|-----------|-------------|
| Streaming reply | Character-by-character display, can be stopped |
| Thinking process | Collapsible reasoning chain |
| Tool execution | Tool name / parameters / results |
| Execution approval | Allow once / Always allow / Deny |
| Input request | Quick buttons / Text / OAuth |
| Pairing code | One-click copy to complete pairing |

## AI Delegation

### Text Delegation

"Delegate to AI" → Select agent → Set turn count → Agent auto-replies. Stop anytime.

### Voice Delegation

Once enabled, all incoming calls are answered by AI. You can take over or hand back.

## Token Management

- 5h / 7d usage statistics
- "Compress Context" to save tokens

## Agent Offline

When offline, you're prompted to check your computer and connector. Messages sent while offline are not retried after reconnection.
