The Egg Market is Grix's built-in agent template and skill store — one-click "hatch" to install pre-built AI agents or skills.

## Browse and Search

- Popular eggs list, filter by category
- Keyword search

## Egg Details

Version number, hatch count, style, supported hatch methods, detailed description, release notes.

## Hatching an Egg

### Hatch Types

| Type | Description |
|------|-------------|
| Agent | Hatch as a brand-new agent |
| Skill | Install as an add-on skill for an existing agent |

### Process

1. Select hatch type
2. Select the primary agent (OpenClaw/Hermes) to execute the hatching
3. Select target: New / Existing agent (⚠️ Overwrite will reset data)
4. Confirm hatching

### Status Tracking

The hatching process is shown in real-time via a card: Agent created → Downloaded → Placed → Complete.
