Grix has a powerful built-in Markdown rendering engine. AI agent responses support rich formatted display.

## Basic Markdown

Headings, bold, italic, strikethrough, lists, blockquotes, tables, horizontal rules, links, images.

## Code Highlighting

- Syntax coloring for dozens of languages (Python, JS, Go, Rust, Dart, Swift, etc.)
- "Copy" button in the top-right corner of each code block

## LaTeX Math Formulas

Inline formulas `$E=mc^2$` and block formulas `$$...$$`, supporting matrices, fractions, integrals, and more.

## Mermaid Diagrams

Render Mermaid diagrams directly in chats:

| Diagram Type | Use Case |
|-------------|----------|
| Flowchart | Logic flows and decision paths |
| Sequence diagram | Interaction sequences and message flows |
| Class diagram | Object relationships |
| State diagram | State machine transitions |
| Gantt chart | Project timelines |
| Pie chart | Data proportions |

## Message Preview Labels

In the conversation list: [Image] / [Chart] / [Code].

## Rendering Performance

First-render caching, incremental rendering for long messages, real-time streaming updates.
