## Categories

| Category | Description |
|----------|-------------|
| Friends | Mutual friends |
| Groups | Group chats you've joined |
| AI Assistants | Workbench entry for coordinating multiple AI agents |

## Add a Friend

Search by username → Click "Add" → Write a verification message → Send friend request.

## Friend Requests

Pending request badge notification: Accept / Decline.

## Create a Group Chat

Enter group name → Select members from friends list → Create.

## Block a User

Once blocked, the user cannot add you as a friend or send you messages.
