虾蛋市场是 Grix 内置的 Agent 模板与技能商店，一键「孵化」安装预制 AI Agent 或技能。

## 浏览与搜索

- 热门虾蛋列表，按分类筛选
- 关键词搜索

## 虾蛋详情

版本号、已孵化次数、风格、支持的孵化方式、详细介绍、版本说明。

## Grix 虾蛋孵化

### 孵化类型

| 类型 | 说明 |
|------|------|
| 智能体 | 孵化为全新 Agent |
| 技能 | 安装为已有 Agent 的附加技能 |

### 流程

1. 选择孵化类型
2. 选择主 Agent（OpenClaw/Hermes）执行孵化
3. 选择目标：新建 / 已有 Agent（⚠️ 覆盖会重置数据）
4. 确认孵化

### 状态跟踪

孵化过程以卡片实时展示：Agent 已创建 → 已下载 → 已落位 → 已完成。
