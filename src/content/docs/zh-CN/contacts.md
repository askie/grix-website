## 分类展示

| 分类 | 说明 |
|------|------|
| 好友 | 已互相添加的真人好友 |
| 群组 | 已加入的群聊 |
| AI 助手 | 协调多个 AI Agent 的工作台入口 |

## 添加好友

输入用户名搜索 → 点击「添加」→ 填写验证留言 → 发送好友申请。

## 好友请求

待处理请求角标提醒：同意 / 拒绝。

## 新建群聊

输入群名 → 从好友列表选成员 → 创建。

## 拉黑用户

拉黑后对方不能添加好友也不能发消息。
