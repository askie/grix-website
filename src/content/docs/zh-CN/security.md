## 通信安全

- WSS 加密长连接
- Token 认证，过期自动重登

## 多设备管理

查看所有登录设备，远程移除踢下线。

## AI Agent 安全

- **执行审批** — Agent 执行命令必须经用户审批（仅允许一次/始终允许/拒绝）
- **权限控制** — 每个 Agent 精细化 Scope 授权
- **密钥管理** — 加密存储、支持轮换、泄露一键失效

## 数据隐私

- Grix **不会**把聊天数据发送给第三方 AI 模型服务商
- 最小数据采集
- 本地缓存用户可随时清理
- 支持完整账号删除（不可恢复）

## 举报机制

举报用户/群聊：选择原因 → 补充说明 → 上传截图 → 提交。

## 安全建议

1. 定期检查设备列表
2. AI 审批默认选「仅允许一次」
3. 不分享 Agent 密钥
4. 使用强密码
