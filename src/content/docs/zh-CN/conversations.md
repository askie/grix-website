消息列表是 Grix 的首页主视图，展示所有会话的实时动态。

## 会话列表

### 会话聚合展示

Grix 将同一联系人下的多个会话聚合为一组，点击展开可查看该联系人的所有对话线程：

- 显示最新消息预览和时间
- 未读消息数角标
- **@我** 角标 — 群聊中有人 @你时显示专属提醒
- 在线/离线状态指示

### 会话操作

长按或右键（桌面端）会话项，可执行以下操作：

| 操作 | 说明 |
|------|------|
| 置顶 | 将会话固定在列表顶部 |
| 取消置顶 | 取消置顶状态 |
| 标记已读 | 清除未读角标 |
| 标记未读 | 手动标记为未读状态 |
| 关闭消息提醒 | 免打扰，不接收该会话的推送通知 |
| 开启消息提醒 | 恢复推送通知 |
| 删除会话 | 删除本地聊天记录（不影响好友关系） |

## 新建聊天

点击消息列表顶部的「+」按钮可以：

- **新建私聊会话** — 选择已有好友发起对话
- **新建群聊** — 选择多位好友创建群组

## 搜索会话

Grix 消息列表顶部提供搜索栏，支持按会话名称、联系人名称进行模糊搜索，快速定位目标对话。

## 扫一扫

点击扫一扫图标，Grix 会启动相机扫描二维码：

- **添加好友** — 扫描对方的 Grix 好友二维码
- **加入群聊** — 扫描群二维码加入
- **扫码登录** — 扫描桌面端/Web 端的登录二维码进行确认

## 我的二维码

展示你的 Grix 好友邀请二维码，支持复制链接和下载二维码图片。

## 桌面端 Agent 工具栏

在 Grix 桌面端（macOS / Windows / Linux），消息列表顶部显示一行 **Agent 工具栏条**：

- 以小图标展示所有已部署的 AI Agent
- 实时状态颜色区分：🟢 在线就绪 / 🟡 忙碌 / 🔴 离线
- 点击图标快速进入对应 Agent 的会话
- 按 Agent 客户端类型分组

## Web 端通知权限

首次在浏览器中使用 Grix Web 版时，顶部会显示通知权限横幅，点击「开启」允许 Grix 推送浏览器通知。
