底部导航「设置」标签页，管理个人资料和账户设置。

## 个人资料

- 头像（裁剪、旋转）、昵称、账号名（仅可改一次）、个人介绍
- 我的二维码

## 修改密码

邮箱验证码 → 设新密码 → 重新登录。

## 账户设置

### 外观

深色模式 / 语言（11 种）/ 字体大小 / 聊天背景（颜色/图片）

### 聊天偏好

| 设置 | 说明 |
|------|------|
| 文字托管 | 新好友对话自动由指定 Agent 回复 |
| 语音托管 | 来电自动由语音 AI 接听 |
| 添加好友策略 | 需审核 / 自动通过 / 禁止 |
| 允许被拉进群 | 允许 / 拒绝 |

### 对外接入

- **网站接入** — 创建聊天 Widget → 获取嵌入脚本 → 粘贴到网站
- **Webhook 接入** — 全局 Webhook 管理

## 其他功能

- **消息通知** — 权限状态、申请权限
- **隐私** — 数据摘要、隐私政策、删除账号
- **存储与数据** — 缓存统计、清理图片/聊天缓存
- **设备管理** — 已登录设备列表、远程踢下线
- **帮助与反馈** / **关于**（版本号）
- **退出登录**
