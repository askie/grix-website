Agent 接入成功后，如何在 Grix 中日常使用。

## 发起对话

入口：AI 列表「会话」按钮 / 消息列表 / 桌面端工具栏 / 通讯录 AI 助手。

## 会话与工作目录

每个 Agent 会话可绑定工作目录（cwd），会话列表按目录分组。

## 新建会话

Agent 会话列表 → 「新建会话」→ Agent 请求选择工作目录 → 提交后开始工作。

## Agent 消息类型

| 卡片类型 | 说明 |
|---------|------|
| 流式回复 | 逐字呈现，可停止 |
| 思考过程 | 折叠展示推理链 |
| 工具执行 | 工具名/参数/结果 |
| 执行审批 | 仅允许一次/始终允许/拒绝 |
| 输入请求 | 快捷按钮/文本/OAuth |
| 配对码 | 一键复制完成配对 |

## AI 托管

### 文字托管

「委托 AI 回复」→ 选 Agent → 设轮数 → Agent 自动回复。随时可停止。

### 语音托管

开启后所有来电由 AI 接听。可接管/交回。

## Token 管理

- 5h / 7d 用量统计
- 「压缩上下文」节省 Token

## Agent 离线

离线时提示检查电脑和 connector，恢复后不补发离线消息。
