在 Grix 中为 Agent 设置工作目录，让 Agent 在指定路径下执行操作。

## 什么是工作目录

工作目录（cwd）= Agent 执行操作的根路径。设置后 Agent 读写文件、执行命令都基于该目录。

## 设置时机

- **新建会话时** — Agent 主动推送「打开工作目录」卡片
- **Agent 主动请求** — 工作过程中请求切换目录

## 操作方式

### 手动输入

在卡片输入框输入路径（如 `/Users/me/projects/my-app`）→ 点击「提交目录」。

### 浏览选择

点击「选择目录」→ 远端文件选择器浏览 Agent 主机文件系统：

- 文件夹导航
- 返回上级 / 根目录
- 收藏夹（常用目录）
- 新建文件夹
- 点击「使用当前目录」确认

## 群聊中的工作目录

### 每个 Agent 独立

群聊可有多个 Agent，各自绑定独立的工作目录，互不影响。

### Agent 消息接收模式

| 模式 | 说明 |
|------|------|
| 正常模式 | 接收所有消息 |
| 仅 @触发 | 仅被 @时响应 |

在群成员列表中找到 Agent → 设置消息接收模式。

## 会话列表按目录分组

```
📁 /projects/frontend    (2 个会话)
📁 /projects/backend     (1 个会话)
📁 未绑定目录            (1 个会话)
```

点击目录标签切换查看。

## 注意事项

- 路径必须是 Agent 主机上的有效路径
- 路径不能为空
- Agent 离线时无法浏览远端文件系统
