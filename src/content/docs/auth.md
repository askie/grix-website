## 服务区域选择

首次使用 Grix 时，需要选择服务区域：

| 区域 | 说明 |
|------|------|
| 中国大陆 | 数据存储于中国大陆服务器 |
| 全球 | Data stored on global servers |

> 切换区域后需要重新获取验证码。

## 注册 Grix 账号

Grix 使用邮箱注册，流程如下：

1. 点击登录页面的「注册账号」
2. 输入邮箱地址
3. 完成图形验证码验证
4. 点击「发送验证码」，Grix 会向邮箱发送 6 位数字验证码
5. 输入邮箱验证码
6. 设置密码
7. 阅读并同意《APP 协议》和《用户协议》
8. 点击「注册」完成

## 登录 Grix

### 账号密码登录

1. 输入账号名或邮箱
2. 输入密码
3. 点击「登录」

**便捷功能**：记住账号和密码，下次打开 Grix 自动填充。

### Google 登录

点击「Google 登录」按钮，通过 Google 账号授权登录 Grix。支持平台：iOS、Android、Web。

### Apple 登录

点击「通过 Apple 登录」按钮，使用 Apple ID 完成 Grix 登录授权。支持平台：iOS、macOS。

### 扫码登录（桌面端 / Web）

1. 在桌面端或 Web 端点击「展开扫码登录」
2. 使用已登录的 Grix 移动端扫描二维码
3. 移动端确认登录请求
4. 桌面端自动完成登录

**状态流转**：等待扫码 → 已扫码等待确认 → 已确认正在登录

> 二维码有有效期，过期后可点击「刷新二维码」重新生成。

## 忘记密码 / 重置密码

1. 在 Grix 登录页点击「忘记密码」
2. 输入注册邮箱
3. 完成图形验证码验证
4. 获取邮箱验证码
5. 设置新密码并确认
6. 点击「重置密码」

重置成功后需使用新密码重新登录 Grix。

## APP 协议与用户协议

Grix 要求用户在注册或首次登录前阅读并同意：

- **APP 协议** — 产品定位、沟通风险提示与使用边界说明
- **用户协议** — 服务规则、权利义务及责任边界

## 登录语言切换

Grix 登录页支持实时切换界面语言，方便多语言用户快速选择。
