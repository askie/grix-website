聊天页是 Grix 的核心交互界面，集成消息收发、AI 对话、语音通话、群聊管理等功能。

## 消息输入与发送

- 文字消息 + Emoji
- **@提及成员** — 输入 `@` 触发选择列表，支持 @全体成员
- **引用回复** — 长按消息选择「引用」
- **发送队列** — 连续发送多条消息，队列面板可查看/删除
- **隐藏发送** — 发送但不触发 Agent 回复，适用于补充上下文

## 附件与多媒体

| 类型 | 来源 |
|------|------|
| 图片 | 相册 / 拍摄 / 桌面端拖拽 / 粘贴 |
| 视频 | 最大 50MB |
| 文件 | 常见文档和压缩文件 |
| 远端文件 | 浏览 Agent 主机文件系统 |

### Grix 图片编辑器

上传前可编辑：裁剪、画笔、箭头、圆圈、矩形、文字标注。支持撤销、缩放、线宽/字号调整。

## 消息操作

长按/右键消息：复制 / 引用 / 转发（逐条/合并/多选）/ 撤回。

## Grix AI 对话能力

### AI 托管回复

1. 点击「委托 AI 回复」→ 选择 Agent → 设置轮数
2. Agent 自动回复对方消息
3. 顶部状态栏显示托管状态，随时可停止

### 实时流式输出

Agent 回复逐字呈现，可点击「停止」中断。

### Agent 思考过程

折叠卡片展示 AI 推理链，点击展开查看。

### 工具执行卡片

Agent 调用工具时以结构化卡片展示名称、参数、结果。

### 执行审批卡片

Agent 执行命令前推送审批：**仅允许一次** / **始终允许** / **拒绝**。有有效期，过期自动失效。

### Agent 输入请求

Agent 需要用户信息时弹出问答卡片：快捷按钮 / 文本输入 / OAuth 跳转。

### Agent 状态

🟢 在线 / 🔴 离线（提示检查电脑和 connector） / ⏳ 思考中

## Grix 语音通话

### 基础操作

发起通话 / 接听 / 拒接 / 静音 / 扬声器 / 挂断 / 最小化

### AI 代接（核心特色）

1. **来电 AI 代接** — 来电时选择 AI Agent 接听
2. **语音托管** — 开启后所有来电自动由 AI 接听
3. **人工接管** — 通话中随时接管
4. **交回 AI** — 接管后可交回 AI 继续

### 通话记录

记录所有通话历史：状态、时长、AI 接听标记。

## 群聊管理

- 邀请好友入群 / 群成员列表
- 设置/取消管理员 / 转让群主 / 移除成员
- 全体禁言 / 单独禁言 / 发言白名单
- Agent 消息接收模式：正常 / 仅 @触发
- 群昵称 / 群二维码 / 退出 / 解散 / 举报

## 会话级功能

- **会话重命名** — 留空自动用首条消息摘要
- **消息提醒开关** — 单独免打扰
- **Webhook 管理** — 为会话创建 Webhook，外部 HTTP POST 推送消息
- **Token 用量** — 5h/7d 用量统计、余额、上下文压缩
