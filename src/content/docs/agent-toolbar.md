桌面端专属功能，集中可视化管理所有本地 Agent。

## 展示模式

| 模式 | 位置 | 说明 |
|------|------|------|
| 紧凑 | 消息列表顶部 | 一行小图标 + 数量角标 |
| 完整 | 系统页内 | 卡片布局 + 文字标签 |

## Agent 状态

- 🟢 健康/就绪 — 进程正常、对话通道已连接
- 🟡 降级/忙碌 — 正在处理任务
- 🔴 异常/离线 — 未启动或连接断开
- ⚪ 未安装

## 点击操作

点击 Agent 类型图标弹出详情对话框：

### 实例列表

每个 Agent 显示：名称、状态、适配器类型、池状态。

### 探测详情

```
CLI: claude v1.2.3
路径: /usr/local/bin/claude
进程: 已启动 · 运行中
对话: 正常 (120ms)
```

### 操作按钮

| 按钮 | 功能 |
|------|------|
| 新增 | 为该类型创建新 Agent 实例 |
| 安装 | CLI 未安装时显示 |
| 🔄 重启 | 重启 Agent 进程 |
| 🗑️ 移除 | 删除实例（需确认） |

## 新增 Agent 流程

「新增」→ 输入名称 → 「创建」→ Grix 自动注册+启动+打开会话。

## 安装 CLI 流程

「安装」→ 检查依赖 → 安装 → 校验 → 完成。缺依赖时提示「安装依赖」。
